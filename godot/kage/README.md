# Kage, designed in Godot

Kage from the character sheet, built in Godot 4.7: a rigged, skinned, animated character exported to glTF for the
Three.js game test in `prototypes/kage-3d/`. Everything is generated by code (GDScript), so a design change is a code
change and one command rebuilds the character, the Godot scene and the `.glb`.

## Build

```bash
godot --headless --path godot/kage --script res://build/build_kage.gd
```

This writes `generated/kage.scn` (the character scene), `generated/kage.glb`, and copies the `.glb` to
`prototypes/kage-3d/assets/kage.glb`. It also dumps every painted texture to `generated/textures/` for inspection.

## Preview in Godot

Open the project in Godot 4.7 and run it (F5), or run `godot --path godot/kage`. `preview.tscn` shows him under a
warm key light and a red back light. **1** idle, **2** walk, **3** / **Space** slash, **T** turntable, drag to
orbit, wheel to zoom. `-- --shot=out.png --anim=slash --t=0.38 --yaw=-60` saves one frame and quits.

## How it is built

```
build/
  build_kage.gd      the entry point: rig + parts + animations -> scene + glTF
  rig.gd             the skeleton: body bones, plus cloth chains (8 round the coat, 2 scarf tails, the apron, 2 tassels)
  anims.gd           idle / walk / slash: poses as data, arms solved by two-bone IK, feet planted, baked at 30 fps
  kit/
    mesh_kit.gd      skinned geometry: grids, ring lofts, tubes, ellipsoids, boxes; one surface per material
    tex_kit.gd       painting in code: polygons, lines, flames, the four-point emblem, the diamond wrap
    materials.gd     the sheet's palette as toon materials (with an ink outline pass for the preview)
  parts/             one file per body part
    face.gd eyes.gd hair.gd scarf.gd torso.gd harness.gd capelet.gd pauldrons.gd arms.gd hands.gd
    belt.gd apron.gd tassel.gd cloak.gd legs.gd boots.gd katana.gd saya.gd common.gd
```

- **Rig**: +Z forward, +Y up, metres; every bone's rest rotation is identity, so a pose rotation is a rotation in
  model axes. The cloth chains carry no animation: Three.js swings them as spring bones.
- **Skinning**: each part says which bones move each point (`[[bone, weight], ...]`): the torso blends hips, spine
  and chest by height, the coat blends the two chains either side of a point and the two bones along them.
- **Eyes**: their own mesh with a `focused` blend shape (keyed during the slash); the red *awakened* glow is a
  material swap in Three.js.
- **Export**: `GLTFDocument` keeps the bones, skin, blend shape, animation tracks, material names, textures and
  double-sided flags. The toon shading and outlines are rebuilt in Three.js (glTF has no toon material).

## Adding another character

Copy `build/parts/` and `rig.gd` into a new project folder, change the parts that differ, and point
`build_kage.gd`'s copy step at a new `.glb` name. The Three.js loader (`prototypes/kage-3d/src/kage/kage.js`) works
for any model built this way: it maps materials by name and finds spring-bone chains by bone name.
